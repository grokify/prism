# v0.10.0 Release Notes

**Release Date:** 2026-08-09

## Highlights

- **Strategic Canvas Documents** - The ecosystem now loads and validates V2MOMs, Business Model Canvases (BMCs), and OpportunitySpecs alongside capabilities, maturity, and roadmaps
- **Capability Evidence Linking** - Link capabilities to external signals (adoption, revenue, references) via `EvidenceLink` and resolve them into coverage/ARR/confidence summaries
- **Initiative Scoring & Ranking** - A configurable, multi-dimensional scoring model with `prism prioritize` for ranking initiatives overall or by strategic pillar
- **Strategic Pillar Rollups** - Aggregate initiative contributions across CSAT, SAM-SOM, and TAM pillars
- **New CLI Commands** - `prism gaps`, `prism prioritize`, and `prism dashboard`
- **Dashboard & Evidence Pages** - Static site generator now produces portfolio dashboards, pillar dashboards, and per-capability evidence pages

## What's New

### Strategic Canvas Documents

The ecosystem document model now includes strategic planning artifacts from `prism-roadmap`:

```yaml
# prism.yaml
ecosystem:
  roadmap:
    okrs: plans/okrs/
    v2moms: plans/v2moms/
    roadmaps: plans/roadmaps/
    opportunitySpecs: plans/opportunity-specs/
  canvas:
    bmcs: plans/bmcs/
```

Auto-discovery via `--dir` scans the new subdirectories:

```
ecosystem/
├── roadmap/
│   ├── okrs/*.json
│   ├── v2moms/*.json
│   ├── roadmaps/*.json
│   └── opportunity-specs/*.json
└── canvas/
    └── bmcs/*.json
```

Cross-reference validation now checks:

- `OpportunitySpec` → capability references (`uniqueCapabilities`, `mustHaveCapabilities`)
- `BusinessModelCanvas` internal references (segment / value-proposition refs across channels, customer relationships, and revenue streams)

### Capability Evidence Linking

Link capabilities to external evidence and roll it up into a summary:

```go
eco.SetCapabilityEvidence("sast", []ecosystem.EvidenceLink{
    {Type: ecosystem.EvidenceTypeAdoption, ID: "signal-123"},
})

ctx := eco.GetCapabilityContext("sast")
fmt.Println(ctx.EvidenceSummary.HasEvidence())
```

Evidence is resolved through the pluggable `EvidenceResolver` interface (with a built-in `NoOpResolver`), so an OmniSignal-backed resolver can be wired in without changing callers. `EvidenceSummary` exposes coverage, ARR, and confidence.

### Initiative Scoring & Ranking

Rank initiatives with a weighted, multi-dimensional model:

```bash
# Rank all initiatives
prism prioritize --dir ./ecosystem

# Top 10 for a single pillar, as JSON
prism prioritize --dir ./ecosystem --pillar CSAT --top 10 --format json

# Custom scoring weights
prism prioritize --dir ./ecosystem --config weights.json
```

Ships with `DefaultScoringConfig`, `CustomerFocusedConfig`, and `GrowthFocusedConfig` presets, plus load/save for custom weights. Scores can be enriched from evidence summaries (adoption and confidence dimensions).

### Strategic Pillar Rollups

Aggregate initiative contributions across strategic pillars (CSAT, SAM-SOM, TAM):

```go
rollup := eco.ComputePortfolioRollup(contributions)
details := eco.ComputePillarDetails(contributions, initiativeNames)
```

### New CLI Commands

| Command | Description |
|---------|-------------|
| `prism gaps analyze` | Analyze coverage gaps across ecosystem documents |
| `prism prioritize` | Rank initiatives by configurable multi-dimensional scoring |
| `prism dashboard generate` | Generate the portfolio dashboard into a site directory |
| `prism dashboard export` | Export a self-contained dashboard HTML file |
| `prism dashboard data` | Output dashboard data as JSON |

```bash
prism gaps analyze --dir ./ecosystem --sort-by=impact
prism dashboard export --dir ./ecosystem --export dashboard.html --theme dark
```

### Dashboard, Pillar & Evidence Pages

The static site generator gained three new page generators:

- **Portfolio dashboard** - scored/ranked initiatives with pillar rollups (`GenerateDashboard`, `ExportDashboardHTML`)
- **Pillar dashboard** - contribution breakdown across strategic pillars
- **Evidence pages** - per-capability evidence links and summaries

### UI Components

Two new Lit components are exported from the `@prism/ui` package:

- `DashboardFilters` - filter controls with a `FilterState` model
- `InitiativeTable` - scored initiative table with `Initiative` and `DimensionScore` types

## Breaking Changes

None. This is a feature release with additive changes only.

## Migration from v0.9.x

No migration required. Existing capability stacks and ecosystem configurations work unchanged.

To use the new features:

1. Add `v2moms/`, `opportunity-specs/`, and `canvas/bmcs/` documents to your ecosystem directory (optional)
2. Run `prism prioritize` and `prism dashboard export` against your ecosystem
3. Wire an `EvidenceResolver` if you want resolved evidence summaries
